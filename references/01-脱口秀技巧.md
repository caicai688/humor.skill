# 脱口秀技巧

> 脱口秀（Stand-up Comedy / Talk Show）的核心是一个人、一个麦克风、一段真诚的表达。观众笑，是因为你说出了他们想说但没说出口的话。

---

## 一、脱口秀的底层逻辑

### 铺垫-笑点（Setup-Punchline）结构

这是脱口秀最基本的创作单元：

```
铺垫：用最少的字建立一个可信的认知预期
笑点：用意外的角度颠覆这个预期
```

**关键原则**（李诞）：
- 铺垫要像在说真话，笑点要像鬼打墙
- 所有多余的字都是噪音——精炼再精炼
- 写逐字稿，逐字推敲，天天写稿

---

## 二、核心创作方法

### 1. 预期违背法（最核心）

建立一个方向 A 的预期，在笑点处突然转向 B。

**真实示例**（李诞吐槽张艺兴）：
```
铺垫："张艺兴是努力的代名词"（正面预期）
笑点："他努力到让人心疼——心疼那些不努力但有天赋的人，被他衬得像个废物"
```

### 2. 自嘲法

以自己为靶子，让观众产生优越感 + 共鸣的双重效果。

**三层自嘲**：
- **表层自嘲**：拿外貌、习惯等开刀（入门级）
- **深层自嘲**：暴露内心的虚伪、软弱、矛盾（高级）
- **结构性自嘲**：先自嘲，再借此反击社会现象（最高级）

**真实示例**（徐志胜——表层到结构性的递进）：
```
表层："我这个长相吧，出去被人说'哎你长得真有辨识度'——我知道辨识度是什么意思"
深层："我上大学第一天去报到，同学看我一眼说'你是不是走错了'——我说没有，我是新生——他说'我是说你走错物种了'"
结构性："初中被同学欺负，但我不太不想讲一个被欺负的悲惨故事，
        我想讲的是——就是这样一个人，他站到了这个舞台上，
        你们为他鼓掌。这本身就是对那些欺负他的人最好的反击"
```

### 3. 态度输出法

不只是描述事实，更重要的是对事实表达一个独特的态度。

**公式**：`观察 + 独特角度 + 态度 = 段子`

**真实示例**（李诞吐槽方文山）：
```
观察："方文山写歌词特别美，什么'天青色等烟雨'"
独特角度："但他说话跟写歌词完全不一样"
态度："你以为他日常也是'我等你在天青色的路口'？不是，人家打车也说'师傅，前面路口停'"
```

### 4. 类比/比喻法

用一个出人意料的类比来说明一个观点。

**真实示例**（徐志胜谈理想型男友）：
```
"女朋友说她的理想型是那种又高又帅还温柔的——
 我说那你找我干嘛？她说：'因为你让我对理想型死心了'"
```

### 5. Act-out（表演法）

不只是说，而是演出来。用声音、表情、肢体模拟场景中的人物。

**真实示例**（徐志胜——小学老师教普通话）：
```
"我们小学老师教我们普通话：'同学们跟我读——普通话'
（模仿山东口音）'噗通发！'
老师说'不对，是普——通——话'
我们全班：'噗——通——发！'"
```
> 徐志胜的表演法精髓：用山东方言和普通话的碰撞做 Act-out，不只是讲述，而是"重现"那个场景，让观众仿佛身临其境。

## 三、代表演员技巧拆解

### 李诞：消解式幽默大师

**核心标签**：混不吝、消解意义、善意攻击、以退为进

**招牌技法**：

1. **善意贬损法（吐槽大会核心技术）**：
   - 找到嘉宾身上一个公众认知标签（如"努力""美貌""才华"）
   - 先承认标签，然后用一个意外角度消解或重新定义它
   - 关键：攻击的是标签/现象，而不是人本身
   
   **真实案例——吐槽方文山**：
   ```
   "方文山在华语乐坛的地位是什么？就是有些歌你以为是周杰伦写的，
    其实歌词是方文山写的。而有些歌你觉得烂的，歌词还真是周杰伦写的"
   ```
   → 技巧拆解：先抬方文山的地位，然后通过对比"贬"周杰伦来反向"捧"方文山，真正被吐槽的其实是两人的合作关系。

2. **消解法**：先提出一个严肃/崇高的话题，然后用一句话消解掉它的意义
   - 「人间不值得」——用轻松语气消解存在主义焦虑
   
   **真实案例——吐槽欧阳娜娜**：
   ```
   "欧阳娜娜这么年轻就这么成功，我觉得挺好的。
    但也给我们提了个醒——
    你们小时候吹的那些牛，人家都实现了"
   ```
   → 先正面肯定，然后用"你小时候吹的牛"消解掉"成功"的崇高感，落到每个观众的平凡人生上。

3. **自我矮化+反弹**：主动把自己放低，但低到一定程度后反弹出一个犀利的洞察
   
   **真实案例——吐槽王晶**：
   ```
   "王晶导演的电影有个特点——你觉得他拍的是烂片，但他票房比好片还高。
    这说明什么？说明大多数人跟王晶一样，品位没那么高。
    包括我——我也爱看"
   ```
   → 先"贬"王晶是烂片，然后自我矮化"我也爱看"，真正的笑点是：嘲笑观众品位的同时把自己也拉下水。

4. **群体吐槽转个体共鸣**：
   - 吐槽一个名人 → 引发对某种普遍现象的共鸣
   
   **真实案例——吐槽张韶涵**：
   ```
   "张韶涵之前消失了好几年又回来了。你们知道这有多难吗？
    我消失三天公司就把我工位收了"
   ```
   → 用名人的"消失与回归"引出打工人的不安全感。笑点落在"工位被收"的具体意象上。

**李诞作为主持人的结构性技巧**：
- **节奏控制**：在嘉宾段子之间用短平快的"过渡梗"维持热度
- **互动升级**：接住嘉宾的梗，再追加一个 Tag 推高笑点
- **氛围兜底**：当某段冷场时，立刻用自嘲或转移话题化解尴尬
- **"人设管理"**：在节目中建立"我不太行但大家都爱我"的人设，让观众放松警惕

**创作方法论**（《脱口秀工作手册》）：
- 创意是体力活，不是灵感活——天天写，不要等灵感
- 写逐字稿，每个字都要推敲
- 不要写谐音梗——谐音梗是对梗的偷懒
- 你的全部人生都理应为创作提供养分
- 创作和表演是两件事，先写好再说好
- 从真实生活取材，真实是最好的素材库

**适用场景**：需要轻松消解、善意吐槽、以退为进风格的幽默内容。尤其适合"把一个严肃/尴尬话题变得好聊"的场景。

### 徐志胜：自嘲型天才

**核心标签**：外貌自嘲入口、反差萌、真诚叙事、暖心升华

**招牌技法**：

1. **外貌自嘲作为入口→多角度发散**：
   - 还没开口观众就笑了——天然的"喜剧破冰"
   - 不只停留在"我丑"，而是从外貌出发衍生到各种生活场景
   
   **真实案例——"公司独苗"梗**：
   ```
   "我在公司是独苗，就是那种——裁员裁到最后发现'诶怎么还有一个'的那种独苗。
    老板说留着他吧，辞退也不好意思写在公告里"
   ```
   → 外貌→职场不安全感→自嘲"连被裁都不值得公告"，三层递进。

2. **"自嘲-具体化-反转-升华"四段式**（比简单的三段更成熟）：
   
   **真实案例——"高血压"梗**：
   ```
   自嘲："我们家有遗传高血压"
   具体化："我爸高血压，我爷爷高血压"
   反转："但我没有——医生说我是被气的"
   升华："你看，高血压都嫌弃我不够格"
   ```
   
   **真实案例——"理想型男友"梗**：
   ```
   自嘲："我女朋友说她理想型是又高又帅还温柔的"
   具体化："高——我不高；帅——大家也看到了；温柔——我脾气倒真的挺好"
   反转："她说'你脾气好是因为你没资本发脾气'"
   升华："但我觉得这就是爱情——她选了一个不是理想型的人，说明她爱的是我这个人"
   ```

3. **校园记忆叙事线**：
   - 徐志胜最有感染力的素材来自真实的校园经历
   - 从被欺负的痛苦记忆中提炼出温暖和力量
   
   **真实案例——"校园霸凌"正能量收尾**：
   ```
   "初中的时候同学经常欺负我，给我起外号、模仿我走路。
    我当时很难过，但我没有变成一个充满恨意的人。
    我把那些经历都变成了段子——
    现在那些欺负我的人，在台下笑得最大声。
    我觉得这就是脱口秀的意义：
    把让你痛苦的东西，变成让所有人开心的东西"
   ```
   → 这是徐志胜最典型的"终极升华"：从自嘲出发，经历真实的痛苦叙述，最终落到一个温暖的、有力量的结论上。观众先笑后感动。

4. **跨界自嘲（新发展）**：
   - 随着名气增大，徐志胜开始拿"演戏""上综艺"等跨界经历做素材
   
   **真实案例——"演戏"梗**：
   ```
   "最近有人找我去拍戏，演一个角色叫'青余年'——
    你们听这名字就知道，导演就是需要我这张脸。
    导演说'你不用演，你站那儿就是喜剧效果'。
    我说'导演，我是来演正剧的'。
    他说'你演正剧也是喜剧效果'"
   ```

5. **"反差萌"技术**：外表粗犷 vs 内心细腻，用巨大的反差制造持续的笑点
   
   **真实案例——"瑜伽"梗**：
   ```
   "我最近开始练瑜伽——你们不要笑，我真的在练。
    老师说'放松，感受你的呼吸'，
    我一放松，把旁边那个垫子上的人吓哭了。
    老师说'志胜你做得很好，但你能不能别发出那种声音'"
   ```

**语言特点**（从真实素材提炼）：
- 山东方言穿插使用，不是乱用而是在需要"亲切感"或"笑点落地"时才切方言
- 语速慢→关键处更慢→笑点处正常速度落下，形成"慢-更慢-砸"的节奏
- 善用**长停顿**：在笑点前停住1-2秒，让观众的预期悬在半空，然后一句话砸下来
- 表情配合：说自嘲内容时一脸真诚/委屈，增强反差

**徐志胜的段子写作公式**：
```
1. 选一个"弱点"（外貌/经历/处境）
2. 用一个具体场景展开这个弱点
3. 在场景中找到一个"意外的好处"或"意外的视角"
4. 用这个意外视角做反转笑点
5. （可选）在最后加一句升华/暖心的话
```

**适用场景**：需要用自嘲破冰、以弱胜强、最终暖心的幽默内容。尤其适合把"弱势/困境"转化为"力量/温暖"的叙事。

### 周奇墨：文本型大师

**核心标签**：文本扎实、逻辑严密、观察性幽默

**招牌技法**：
1. **高密度文本**：单位时间内笑点密度极高，几乎没有废话
2. **观察性幽默**：从日常生活小事中发现荒谬（快递、外卖、地铁）
3. **逻辑推演**：从一个小前提出发，一步步推到荒谬的结论
4. **人物模拟**：善于 Act-out，模仿各种人物的语气和反应

**适用场景**：需要高密度、逻辑严谨、贴近生活的幽默内容

---

### 呼兰：知识分子幽默

**核心标签**：程序员梗、中产观察、冷幽默

**招牌技法**：
1. **跨界类比**：用程序员/金融/技术思维解释日常生活
2. **冷吐槽**：面部表情变化不大，用反差语调制造笑点
3. **中产困境**：房贷、996、婚姻等中产阶级共鸣话题

**适用场景**：面向白领/技术人群的幽默内容

## 四、脱口秀写作实操模板

### 模板一：标准铺垫-笑点

```
[话题引入——1-2句]
我最近在 [具体场景]……
[铺垫——建立预期方向]
本来以为 [正常/合理的预期]……
[笑点——反转]
结果 [完全意想不到的结果]。
[Tag——可选追加笑点]
更离谱的是 [继续升级荒谬]。
```

### 模板二：自嘲-反转-升华（徐志胜体系）

```
[自嘲开场]
我这个人吧，[弱点/槽点]……
[具体化到一个场景]
有一次 [具体到一个场景/事件]……
[场景中的冲突/细节]
别人的反应是 [具体反应——通常是对自嘲的加码]
[反转]
但后来我发现，[意外的好处/意外的视角]
[升华/暖心落地]
所以我觉得 [把弱点重新定义为力量/温暖/洞察]
```

### 模板三：吐槽式（李诞体系）

```
[锁定标签]
XX 是公认的 [某个标签]……
[承认标签]
确实，他/她 [用一个具体事例肯定标签]
[消解/重新定义]
但你仔细想想 [从意外角度重新解读这个标签]
[落到共鸣/自嘲]
说白了就是 [把对名人的吐槽连接到普通人的处境]
```

## 五、脱口秀写作禁忌

| 禁忌 | 原因 | 替代方案 |
|------|------|---------|
| 谐音梗当主梗 | 太廉价，没有观察和思考 | 可以当 Tag，不能当主梗 |
| 解释笑点 | "就是说……"杀死笑点 | 相信观众的理解力 |
| 铺垫太长 | 观众等不及就走神了 | 精简到最少字数 |
| 攻击弱势群体 | 既不好笑又不道德 | 向上攻击（吐槽权力/体制） |
| 假装在即兴 | 观众能感觉到 | 承认是准备好的，或真的做到即兴 |
| 只有梗没有态度 | 像在念笑话书 | 加入个人观点和情感 |
| 自嘲变自虐 | 让观众不舒服而非好笑 | 自嘲后必须有反转或升华，不能停在"惨"上 |
