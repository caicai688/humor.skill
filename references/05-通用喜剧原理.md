# 通用喜剧原理

> 所有喜剧的底层逻辑都是操控「预期」与「意外」的落差。不同流派只是实现手段不同。

---

## 一、四大喜剧心理学理论

### 1. 失谐理论（Incongruity Theory）——最核心

- **原理**：幽默源于「预期」与「实际结果」之间的不协调。铺垫建立认知框架，笑点打破预期。
- **康德名言**：「紧张的期待突然化为乌有。」
- **应用**：脱口秀的铺垫-反转结构、相声的三翻四抖、Sketch 的情境反转，本质都是失谐。
- **写作要点**：铺垫越可信、越具体，反转的冲击力越大。

**真实案例**（李诞吐槽张韶涵）：
```
铺垫："张韶涵之前消失了好几年又回来了。你们知道这有多难吗？"
预期：接下来应该说"所以她很了不起"
实际："我消失三天公司就把我工位收了"
→ 失谐点：名人的"消失与回归"vs 打工人的"消失就被淘汰"
```

### 2. 优越感理论（Superiority Theory）

- **原理**：笑声源于感知到自身相对于他人（或过去的自己）的优越感。
- **霍布斯名言**：「突然的荣耀感。」
- **应用**：自嘲（让观众对"过去的我"产生优越感）、吐槽（对靶子的善意贬损）。
- **写作要点**：自嘲比攻击他人更安全，也更高级。

**真实案例**（徐志胜"公司独苗"梗）：
```
"我在公司是独苗，就是那种——裁员裁到最后发现'诶怎么还有一个'的那种独苗。
 老板说留着他吧，辞退也不好意思写在公告里"
→ 观众优越感来源：比徐志胜在公司的处境"好"，但同时共鸣："我是不是也差不多？"
→ 优越感+共鸣的双重击中
```

### 3. 释放理论（Relief Theory）

- **原理**：幽默是心理/生理紧张的宣泄口。在压抑、禁忌、焦虑情境下，笑声释放被积压的能量。
- **弗洛伊德**：笑是压抑能量的释放途径。
- **应用**：黑色幽默、禁忌话题喜剧、社会讽刺、职场段子。
- **写作要点**：先制造紧张/禁忌感，再用笑点一次性释放。

**真实案例**（酷酷的天放《史上第一大劫案》）：
```
劫匪闯入银行 → 紧张感建立（观众本能紧张）
员工说："既然你把老板绑了，能不能顺便帮我们要下加班费？"→ 紧张释放为笑声
小孩递零花钱给劫匪："叔叔你拿着，看起来你比我更需要" → 二次释放
→ 释放的本质：打工人对"被压榨"的日常焦虑，通过荒诞情境一次性释放
```

### 4. 良性冲突理论（Benign Violation Theory）

- **原理**：幽默必须同时满足两个条件——「冲突」（违反规范）且「良性」（无害）。
- **应用**：冲突过小无趣，过大引发不适。必须找到"甜蜜点"。
- **写作要点**：攻击性内容要有安全网（自嘲框架、夸张到不可能、明确的虚构标记）。

**真实案例**（蒋龙张弛《孙悟空选角》）：
```
冲突：讽刺娱乐圈的"资方决定选角"潜规则（真实且尖锐）
良性：放在了"西游记拍电影"这个荒诞框架中，没有指名道姓
甜蜜点：观众知道"这在影射真实现象"，但因为是虚构情境，笑得出来而不会不舒服
→ 如果直接说"某某导演向资方低头"就太冒犯了，但包在孙悟空选角里就刚好
```

## 二、通用喜剧结构

### 基本单元：铺垫 → 笑点

```
铺垫（Setup）：建立情境，引导受众形成预期
    ↓
转折（Turn）：认知重构的瞬间
    ↓
笑点（Punchline）：颠覆预期的结论
```

### 增强技巧

| 技巧 | 说明 | 真实示例 |
|------|------|---------|
| **笑点叠加（Tag）** | 主笑点后追加补充笑点 | 徐志胜："我没有遗传高血压——医生说我是被气的"（主笑点）"高血压都嫌弃我不够格"（Tag） |
| **回调（Callback）** | 后面引用前面的笑话，建立内部默契 | 四世同堂《八十一难》：沙僧在结尾终于说出了被打断了一整集的那句话 |
| **三的法则（Rule of Three）** | 前两项建立模式，第三项打破 | 李诞吐槽：方文山能写诗、能写歌、能写对联——就是不能写通知 |
| **升级（Escalation）** | 荒谬感不断递增 | 张兴朝《冷不丁梆梆就两拳》：正常打斗→奇怪招式→完全不打了→突然又梆梆两拳 |
| **反复（Running Gag）** | 同一个梗反复出现但每次变化 | 张兴朝《棒棒小卖部》："棒棒小卖部"被用各种方式重复（说/唱/戏腔/Rap/全场合唱） |

## 三、十三种喜剧结构（Jerry Corley 体系 + 真实案例）

1. **语义双关（Double Entendres）**：利用词语多义性
2. **反转（Reverses）**：颠覆铺垫建立的预期
   - 案例：杨雨光《开学第一天》——每次你以为知道他是谁了，他又换了一个身份
3. **三的法则（Triples）**：两正一反，打破模式
4. **夸张（Exaggeration）**：放大到荒谬程度
   - 案例：四世同堂《越狱的夏天》——二狗扰民的程度从"吵闹"升级到"动用大型机械"
5. **轻描淡写（Understatement）**：与夸张相反，用平淡语气说大事
   - 案例：李诞消解式——"人间不值得"，用最轻的语气说最重的话
6. **误解（Misunderstanding）**：角色间的信息不对称
   - 案例：刘同某某某《遇人不熟》——每一对"陌生人"其实都认识
7. **类比（Analogy/Comparison）**：把不相关事物做意外类比
8. **模拟（Act-out/Mimicry）**：模仿人物、场景的声音和动作
   - 案例：徐志胜模仿山东小学老师教普通话
9. **角色错位（Fish Out of Water）**：人物不属于当前环境
   - 案例：杨雨光《游泳有谋》——现代思维在秦朝兵马俑工坊
10. **回调（Callback）**：引用之前的笑点
11. **时事关联（Topical）**：与当下热点结合
12. **黑色幽默（Dark Humor）**：对严肃话题的喜剧化处理
    - 案例：刘同某某某《复活军团》——把"遗书乌龙"处理成温暖而非恐惧
13. **自嘲（Self-deprecation）**：以自己为靶子
    - 案例：徐志胜的整个表演体系都建立在自嘲之上

## 四、喜剧节奏学

### 节奏公式

- **目标**：每分钟 4-6 次笑声（开放麦标准）
- **LPM（Laughs Per Minute）**越高，段子越紧凑

### 核心节奏工具

| 工具 | 作用 | 真实示例 |
|------|------|---------|
| **停顿（Pause）** | 给观众反应时间，制造预期 | 徐志胜在笑点前的长停顿——1-2秒的沉默让观众悬在半空 |
| **加速（Rush）** | 快速铺垫，不给思考时间 | 张兴朝的节奏密集段，笑点像子弹一样连射不给喘息 |
| **重音（Emphasis）** | 强调笑点关键词 | 杨雨光"干拔"时的情绪重音——关键词被拔高两个音调 |
| **留白（Beat）** | 笑点后的沉默，等待笑声 | 蒋龙张弛温情转折后的2-3秒留白，让观众消化情感 |
| **语调变化** | 用声音的起伏传递情绪反差 | 杨雨光从平静→暴怒→平静的三段式语调变化 |

### Sketch 特有的节奏工具

| 工具 | 作用 | 真实示例 |
|------|------|---------|
| **角色轮换** | 不同角色轮流出击，维持注意力 | 酷酷的天放群戏中 A→B→C→D 的轮盘节奏 |
| **音乐切入** | 用音乐打断对话节奏，制造惊喜或情感转折 | 蒋龙张弛《杀手不太冷》的歌声突然响起 |
| **场景跳切** | 快速切换场景打破观众的节奏预期 | 四世同堂《八十一难》九世轮回的快速跳切 |

## 五、喜剧人格（Comic Persona）

每个成功的喜剧演员都有独特的「喜剧滤镜」——他们看世界的独特方式。

### 常见喜剧人格类型（含真实代表）

| 类型 | 特征 | 代表 | 真实标志 |
|------|------|------|---------|
| **自嘲者** | 拿自己开刀，越惨越好笑，但最终暖心 | 徐志胜 | "高血压都嫌弃我不够格" |
| **消解者** | 满不在乎的态度消解严肃 | 李诞 | "人间不值得"式的轻松虚无 |
| **炸裂型** | 情绪爆发，干拔情绪核弹 | 杨雨光 | 毫无预兆的情绪拉满 |
| **荒诞制造机** | 不讲逻辑，纯粹输出荒谬 | 张兴朝 | 魔性歌曲+无意义行为 |
| **温情建筑师** | 用笑声搭建情感的桥梁 | 蒋龙张弛/刘同某某某 | 笑着笑着就哭了 |
| **人设操控师** | 精心设计角色碰撞，弱者最终胜出 | 酷酷的天放 | "打不倒的人才值得尊重" |
| **群戏指挥家** | 多角色同台调度，经典IP新解 | 四世同堂 | 沙僧存在感危机 |
| **知识分子型** | 用学识和逻辑制造幽默 | 刘旸 | 用词源学解释deadline |
| **市井型** | 接地气的生活智慧 | 郭德纲 | 市井语言+包袱密集 |

## 六、创作迭代流程

```
1. 素材收集 → 从个人经历、日常观察、热点中搜集
     ↓
2. 选风格/人格 → 确定喜剧人格和技法组合
     ↓
3. 初稿撰写 → 写出完整的铺垫-笑点结构
     ↓
4. 精炼压缩 → 删除一切不服务于笑点的文字
     ↓
5. 升级检查 → 荒谬度是否逐层递增？有没有Tag/Callback？
     ↓
6. 情感检查 → 如果需要温情，铺垫够不够？转折自然吗？
     ↓
7. 测试反馈 → 给真人读/开放麦测试
     ↓
8. 迭代优化 → 根据反馈调整节奏、措辞、顺序
     ↓
9. 定稿打磨 → Kill your darlings，删掉你最喜欢但不好笑的部分
```

## 七、"好笑"的检查清单

写完一段幽默内容后，逐项检查：

- [ ] **有没有铺垫？** 读者的预期是否被明确建立？
- [ ] **反转够不够意外？** 笑点是否真的颠覆了预期，而不是顺着说？
- [ ] **够不够具体？** 是否用了精确的细节而不是模糊的描述？
- [ ] **有没有多余的字？** 每个字是否都服务于铺垫或笑点？
- [ ] **节奏对不对？** 笑点前有没有不必要的拖沓？
- [ ] **安全吗？** 冒犯性内容是否有安全网？
- [ ] **能不能加 Tag？** 主笑点后能否再追一个？
- [ ] **能不能回调？** 后面能否引用前面的梗？
- [ ] **升级够不够？** 荒谬度是否逐层递增，还是一直平着走？
- [ ] **情感对不对？** 如果有温情部分，是"被打到"还是"被硬塞"？
