# Sketch 喜剧技巧

> Sketch（素描喜剧/短剧喜剧）是有情节、有角色的短篇喜剧表演。不同于脱口秀的"一人说"，Sketch 靠情境、角色互动和戏剧冲突制造笑点。

---

## 一、Sketch 的本质

**一句话定义**：在一个极端/荒诞的情境中，角色们的认真反应产生的喜剧效果。

**核心公式**：
```
异常情境 × 正常反应 = 喜剧
正常情境 × 异常反应 = 喜剧
```

**与脱口秀的区别**：
| 维度 | 脱口秀 | Sketch |
|------|--------|--------|
| 表演人数 | 通常1人 | 2人以上 |
| 笑点来源 | 文本+态度 | 情境+角色+互动 |
| 结构 | 铺垫-笑点 | 前提-升级-高潮 |
| 观众代入 | 听故事 | 看故事发生 |
| 核心能力 | 写作 | 写作+表演+调度 |

---

## 二、Sketch 的六大喜剧引擎

### 1. 前提荒谬（Game of the Scene）

每个好的 Sketch 都有一个"Game"——一个核心的荒谬前提。

**找 Game 的方法**：
- "如果……会怎样？"（What if?）
- 把一个普通场景的某个变量调到极端
- 在正常世界里插入一个不正常的元素

**真实示例**：
- 《技能五子棋》（张兴朝）：如果下棋的输赢决定你必须表演各种荒谬技能？
- 《八十一难》（四世同堂）：如果西天取经只有八十难，师徒四人得凑第八十一难才能成佛？
- 《史上第一大劫案》（酷酷的天放）：如果银行遇到劫匪，员工们趁机提各种诉求？
- 《质子的愿望》（酷酷的天放）：如果七国质子聚在一起像选秀节目一样选团长？

### 2. 升级（Heightening）

在建立了 Game 之后，不断把荒谬程度往上推。

```
第一拍：荒谬度 3/10
第二拍：荒谬度 5/10
第三拍：荒谬度 7/10
高潮：荒谬度 10/10
```

**真实示例——《越狱的夏天》（四世同堂）的升级路线**：
```
第一拍：二狗在监狱外搞噪音扰民（荒谬度 3/10）
第二拍：梁山好汉决定越狱去打二狗（荒谬度 5/10）
第三拍：每个好汉用自己的绝技越狱（武松打虎式破墙、鼓上蚤轻功、入云龙挖地道）（荒谬度 7/10）
高潮：发现二狗就是监狱派来故意激他们"自愿加时"的（荒谬度 10/10）
```

**升级的方向**：
- 数量升级：从1个变成100个
- 程度升级：从小问题变成大灾难
- 范围升级：从一个人蔓延到所有人
- 逻辑升级：从可以理解变成完全不可理喻
- 角色升级：越来越多的角色卷入同一个荒谬

### 3. 角色错位（Fish Out of Water）

把一个人放在他完全不属于的环境里。

**真实示例**：
- 《开学第一天》（杨雨光）：36岁的"高三学生"在新班级里，年龄/身份与环境完全错位
- 《游泳有谋》（杨雨光）：现代人的思维方式出现在秦朝兵马俑工坊
- 《穿越》（蒋龙张弛）：未来的自己穿越回来告诉年轻的自己京剧梦想不值得
- 《遇人不熟》（刘同某某某）：海盗船上所有人都互相认识，只有主角是真正的"陌生人"

**经典错位组合**：
- 古代人 vs 现代场景
- 外星人 vs 日常生活
- 小孩 vs 成人世界
- 内行 vs 外行
- 强者 vs 弱者的身份互换

### 4. 身份反转

角色的身份/地位/能力在某个瞬间发生逆转。

**真实示例**：
- 《开学第一天》（杨雨光）：班长→保安→纪律委员→混混→最后发现是班主任的父亲，身份不断反转
- 《杀手不太冷》（蒋龙张弛）：冷酷的杀手在执行任务时唱出天籁之音，身份从"杀手"反转为"歌手"
- 《孙悟空选角》（蒋龙张弛）：导演（张一谋）有艺术理想 vs 制片人（蒙总）只看资本，两人在权力上不断反转
- 《高考状元》（酷酷的天放）：从全村骄傲的680分状元→抄错成绩的180分落榜生，身份一夜翻转

**模式**：强者变弱、弱者变强、权威崩塌、小人物逆袭

### 5. 信息不对称

某些角色知道而其他角色不知道的信息，制造戏剧张力。

**真实示例**：
- 《密室逃脱》（蒋龙张弛）：扮丧尸的NPC其实是主角的中学老师，两人互相不知道对方身份，观众通过线索逐渐明白
- 《遇人不熟》（刘同某某某）：海盗船上每个人都有多重身份（老同学/邻居/狱友），每次揭示一层身份都产生新笑点
- 《X计划》（四世同堂）：多个抢银行团伙互相不知道对方也在抢同一家银行
- 《心动的信号》（四世同堂）：西西里里家族的遗产分配中，每个人手里都握着不同的"坏消息"

**三种类型**：
- 观众知道角色不知道（dramatic irony，产生期待感）
- 角色之间信息不对等（误会型喜剧）
- 角色知道观众不知道（悬念，揭示时产生惊喜）

### 6. 重复与变奏

同一个 Game 反复出现，但每次都有变化。

**真实示例——《冷不丁梆梆就两拳》（张兴朝）**：
```
第一次：被"冷不丁梆梆就两拳"打了 → 观众笑
第二次：学了武功去对付"冷不丁"，结果又被以不同方式打了 → 更笑
第三次：全副武装防备，结果对方完全换了一种迷惑行为 → 爆笑
```

**真实示例——《棒棒小卖部》（张兴朝）**：
```
第一次：正常介绍商品 → 正常
第二次：开始用夸张方式推销 → 笑
第三次：完全变成电视购物+清仓甩卖模式 → 爆笑
第四次：连现场观众都被"卖"进去了 → 炸
```

## 三、代表演员/团队技巧拆解

### 蒋龙 & 张弛（"逐梦亚军"）：情感型 Sketch

**核心标签**：默契配合、笑中带泪、小人物追梦、音乐驱动、行业讽刺

**招牌技法**：

1. **"笑着笑着就哭了"结构**：
   - 前70-80%是纯喜剧，笑点密集不断升级
   - 最后20-30%突然转入情感，一句台词或一个画面击中观众
   - 关键：情感转折必须是"有铺垫的突然"——前面埋的线索在这一刻串起来
   
   **真实案例——《密室逃脱》**：
   ```
   喜剧段：主角在密室逃脱里遇到一个超级敬业的丧尸NPC（26号），
           丧尸跳拉丁舞追人、学各种恐怖电影桥段
   情感转折："26号"摘下面具，是主角初中的班主任老师。
           老师说："没有小角色，只有小演员"——
           这句话既是对自己当NPC的自嘲，也是对所有认真做"小事"的人的致敬
   ```

2. **音乐作为情感催化剂**：
   - 蒋龙张弛的作品中，音乐不只是配乐，而是剧情推动力和情感爆发点
   
   **真实案例——《杀手不太冷》**：
   ```
   杀手蒋龙执行任务时被迫唱歌，结果唱出了惊人的天籁之音。
   音乐从"搞笑道具"变成了"暴露内心"的工具——
   冷酷的外表下是一个有音乐梦的灵魂
   ```
   
   **真实案例——《穿越》**：
   ```
   年轻人学京剧被嘲笑，未来的自己穿越回来说"别学了没前途"。
   但最终年轻人坚持了。吉他弹奏的段落是全场最安静也最感动的瞬间——
   观众在笑了十分钟之后，突然被音乐打到了
   ```

3. **行业讽刺（新维度）**：
   - 不只做小人物故事，也开始讽刺行业现象
   
   **真实案例——《孙悟空选角》**：
   ```
   导演张一谋（蒋龙饰）想要拍好作品，制片人蒙总（张弛饰）只看资方关系。
   选角过程变成了"艺术vs资本"的博弈：
   - 来了一个只会说"大圣饶命"的演员，但他是资方的人
   - 导演坚持要演技，但没有话语权
   - 最后的笑点与辛酸并存：真有本事的人进不了剧组
   ```
   → 蒋龙张弛的升级方向：从纯情感故事 → 情感+行业洞察，讽刺更有深度了

4. **默契互动产生的化学反应**：
   - 两人的配合不只是"你说一句我说一句"，而是通过眼神、节奏、语气的微调产生额外的喜剧效果
   - 蒋龙偏"正"（直球、深情、认真），张弛偏"谐"（插科打诨、消解、制造意外）

**蒋龙张弛的 Sketch 创作公式**：
```
1. 选一个观众有共鸣的"小人物处境"（追梦/打工/被误解）
2. 设置一个荒谬的情境让主角进入
3. 前半段用密集笑点建立喜剧节奏
4. 在某个"看似荒谬的瞬间"里，埋入真情实感的种子
5. 结尾：让那颗种子爆发，笑声变成泪水（或至少是"鼻子一酸"）
```

**适用场景**：需要有温度、有情感层次的幽默内容。"先让人笑，再让人想，最后让人感动"。

### 张兴朝 & 李嘉诚（"外星从"）：无厘头 Sketch

**核心标签**：无厘头、魔性洗脑、纯粹搞笑、技能展示、荒谬递进

**招牌技法**：

1. **无厘头至上——拒绝意义**：
   - 不需要合理的逻辑，荒诞本身就是目的
   - 和其他 Sketch 团队最大的区别：其他人是"用荒诞讲道理"，张兴朝是"荒诞本身就是道理"
   
   **真实案例——《技能五子棋》**：
   ```
   游戏规则：下棋输了要表演一个技能。
   技能内容完全没有逻辑——魔方、吃辣椒、空翻、唱歌、同时做以上所有。
   没有任何"人生感悟"或"情感升华"，
   纯粹就是"看到一个人被迫做各种离谱事情"的快乐
   ```

2. **魔性重复+洗脑旋律**：
   - 用一段朗朗上口的旋律或台词反复出现，在观众脑中种下"魔性循环"
   - 重复不是简单重复，每次出现都会有微妙变化（节奏/音调/搭配的动作不同）
   
   **真实案例——《棒棒小卖部》**：
   ```
   "棒棒小卖部"这个广告词被用各种方式重复：
   正常说→唱出来→用戏腔唱→用Rap唱→现场让观众一起喊→
   每一次变化都让观众更加上头
   ```

3. **技能展示型喜剧**：
   - 张兴朝本人多才多艺（唱歌、舞蹈、模仿、杂耍），把才艺本身变成笑点
   - 才艺越厉害，和荒诞情境的反差越大，越好笑
   
   **真实案例——三部曲连续技能展示**：
   ```
   《技能五子棋》：真正的才艺展示（空翻、魔方、歌曲）穿插在荒谬规则中
   《棒棒小卖部》：用真实的推销才能卖一堆不存在的商品
   《冷不丁梆梆就两拳》：武术/体操/迷惑行为连续展示
   ```

4. **现场互动+第四面墙突破**：
   - 张兴朝经常打破第四面墙，直接和观众互动
   - 把现场观众拉进荒谬世界中，让观众从"看"变成"参与"
   
   **真实案例——《棒棒小卖部》的现场广告**：
   ```
   直接对着镜头/观众做电视购物式推销：
   "家人们！今天棒棒小卖部清仓大甩卖！买一送——算了送你两个！"
   观众被从"看Sketch"拉入"看直播带货"的状态
   ```

5. **迷惑行为递进**：
   - 从"有点奇怪"→"很奇怪"→"完全无法理解"→"观众已经放弃理解开始纯笑"
   
   **真实案例——《冷不丁梆梆就两拳》**：
   ```
   阶段1：正常打斗 → 还能理解
   阶段2：用奇怪招式打 → 开始迷惑
   阶段3：根本不打了，开始做完全无关的事情 → 观众大脑宕机
   阶段4：突然又梆梆就两拳 → 观众：还能这样？！
   ```

**张兴朝的核心创作原理**：
```
1. 找一个简单的游戏规则或情境
2. 不断往里面塞进"不应该出现在这里"的元素
3. 每次升级都要超出观众的想象边界
4. 不需要结论、不需要升华，在最荒诞的地方戛然而止
5. 如果能加一首魔性歌曲，加上去
```

**适用场景**：需要纯搞笑、洗脑、不需要深度、让人"笑到忘记烦恼"的娱乐内容。

### 杨雨光 & 李明磊：干拔式 Sketch

**核心标签**：干拔之王、多重身份反转、情绪核弹、一本正经演荒诞、暖心落地

**招牌技法**：

1. **干拔（Hard Pull）——招牌中的招牌**：
   - 定义：在没有足够铺垫的情况下，通过表演的爆发力强行把情绪拉到满格
   - 关键要素：演员必须100%投入，越认真越好笑
   - 效果：观众被突如其来的情绪冲击逗笑，同时又被表演的真诚打动
   
   **真实案例——《游泳有谋》中的情绪爆发**：
   ```
   小舅子冒充兵马俑被发现，面临杀头。
   杨雨光饰演的将军突然从搞笑模式切到"悲壮模式"：
   "我蒙恬为将二十年，从未杀过一个无辜之人！"
   （全场从笑变成安静，然后下一秒又因为反差笑到崩溃）
   ```

2. **多重身份反转——层层揭面**：
   - 杨雨光的角色永远不是你以为的那个身份
   - 每一次身份揭露都是一次笑点爆发
   
   **真实案例——《开学第一天》的身份反转链**：
   ```
   第一层：36岁高三班长（离谱但接受）
   第二层：原来他同时是学校保安（双重身份）
   第三层：其实还是纪律委员（三重身份）
   第四层：还有一个"混混"的身份（四重身份）
   最终揭露：他是新班主任的父亲——所有身份都是为了"保护"儿子
   ```
   → 关键技术：每一层身份都在前面有伏笔，揭露时观众恍然大悟"原来如此！"

3. **历史/奇幻情境+现代思维的碰撞**：
   - 把现代人的价值观和语言放进古代/奇幻场景中
   - 反差天然产生喜剧效果
   
   **真实案例——《游泳有谋》**：
   ```
   设定：秦朝的兵马俑制作工坊。
   但角色们的说话方式完全是现代的：
   "这个兵马俑的KPI达标了吗？"
   "你这个造型不行，甲方——哦不，始皇帝不会满意的"
   小舅子"冒充兵马俑"的桥段更是：用现代的"临时工思维"理解古代的"殉葬制度"
   ```

4. **"人保戏"——靠表演力量提升文本**：
   - 杨雨光的表演能力可以把7分的剧本演到9分
   - 同一句台词在他的语气、表情、节奏加持下效果翻倍
   - 特别是**眼神表演**：在关键时刻一个眼神就能制造巨大的喜剧效果

5. **暖心收尾——荒诞之后的温情**：
   - 虽然过程荒诞搞笑，但结尾往往落到亲情/友情/人性的温暖上
   
   **真实案例——《游泳有谋》结尾**：
   ```
   整个故事是在搞笑，但最后蒙恬将军选择放了小舅子，
   说了一句"参军吧，做一个堂堂正正的人"。
   观众在笑了全程之后，突然被这句话的真诚打到了
   ```
   
   **真实案例——《开学第一天》结尾**：
   ```
   所有身份反转的笑料之后，
   最后揭示：他做这一切都是为了第一天当老师的儿子"撑场子"。
   "以教代学"——教室里的父爱
   ```

**杨雨光的"干拔"写作应用**：
```
[正常情境，平静叙述，1-3拍建立"安全感"]
→ [突然，毫无预兆地]
→ [角色情绪拉满/做出极端行为/说出完全不合时宜的话]
→ [其他角色/观众：???]
→ [笑点产生]
→ [快速恢复平静，或继续升级到更高的干拔]
```

**适用场景**：需要爆发力强、身份反转层层递进、最终暖心落地的幽默内容。

### 酷酷的天放：人设驱动型 Sketch

**核心标签**：人设鲜明、群戏调度、暖心反转、古今穿插、强情节

**招牌技法**：

1. **强人设驱动——每个角色都有"灵魂"**：
   - 不靠段子堆砌，而是每个角色的性格设定本身就产生笑点
   - 角色之间的性格碰撞是主要笑点来源
   
   **真实案例——《质子的愿望》中的人设设计**：
   ```
   七个质子的人设各不相同：
   - 秦国质子：霸道、自信、"天下都是我爹的"
   - 韩国质子（天放饰）：看似最弱、最怂，实际最有智慧
   - 赵国质子：武力值高但脑子简单
   - 燕国质子：阴郁、文艺
   每个人设都是一个独立的笑点来源，互动时产生化学反应
   ```

2. **"弱者胜出"叙事模式**：
   - 天放偏爱塑造"看起来最弱但最终赢了"的角色
   - 观众天然代入弱者视角，当弱者翻盘时获得双重满足（笑+爽）
   
   **真实案例——《质子的愿望》**：
   ```
   韩国质子是七国中最弱的，被所有人看不起。
   但他用"示弱策略"让其他六国互相消耗，
   最后秦王选他当"团长"——
   因为"一个总是被打但从不倒下的人，才是真正值得尊重的人"
   
   父亲（韩王）的台词："我不需要你成为最强的，
   我只需要你成为一个打不倒的人"
   → 笑到最后，这句话让全场安静了
   ```

3. **现实共鸣嫁接历史/奇幻**：
   - 用古装/奇幻外壳包裹当代人的真实困境
   - 让观众"笑着照镜子"
   
   **真实案例——《史上第一大劫案》**：
   ```
   劫匪闯入银行，但银行员工的反应不是害怕，而是趁机提诉求：
   "既然你把老板绑了，能不能顺便帮我们要下加班费？"
   "能不能把那台打印机也抢走？我天天修它我都疯了"
   小孩把零花钱塞给劫匪："叔叔你拿着，看起来你比我更需要"
   
   → 表面是银行劫案，实际是打工人困境的集中爆发
   ```

4. **群戏调度——多人同台的节奏控制**：
   - 天放的作品通常有4-6个主要角色同台
   - 每个角色都有自己的笑点线，不互相抢戏但互相烘托
   - 用**轮流出击**的方式保持笑点节奏：A角色的笑点→B角色接住→C角色升级→A角色回来
   
   **真实案例——《高考状元》的多角色调度**：
   ```
   角色分工：
   - 天放（状元本人）：核心人物，情绪主线
   - 哥哥（开小卖部）：喜剧担当，夸张反应
   - 邓老师：催化剂角色，每次出现推动剧情反转
   - 街坊四邻：群众反应，放大效果
   
   节奏：天放说一句→哥哥夸张反应→邻居起哄→邓老师打断→
        天放再说一句→全场节奏被这个"轮盘"驱动
   ```

5. **暖心反转——在最搞笑的地方突然认真**：
   - 和蒋龙张弛不同，天放的暖心不是在结尾，而是**穿插在笑点之间**
   - 笑着笑着突然被一句台词戳到，还没反应过来又开始笑了
   
   **真实案例——《抢婚》**：
   ```
   全程在搞笑：天放、管月、凌峰三角恋+水浒传梗+各种打斗。
   但中间穿插了一段：
   "我从小到大，最怕的不是你嫁给别人，
    是你嫁给别人之后比跟我在一起更开心"
   → 观众正在笑，这句话像一根针扎了一下
   下一秒又回到搞笑→形成"笑-痛-笑"的心率过山车
   ```

**酷酷的天放的 Sketch 创作公式**：
```
1. 设计3-6个性格鲜明、互相碰撞的人设
2. 把人设放进一个有压力的情境中（劫案/考试/选拔/婚礼）
3. 让人设之间的性格差异自然产生冲突和笑点
4. 在群戏中保持节奏——每个角色轮流出击，无冷场
5. 在密集笑点中穿插1-2句真心话，让观众心头一热
6. 结尾要暖，但不要煽情——点到为止
```

**适用场景**：需要多角色互动、人设驱动、有现实共鸣、暖而不腻的幽默内容。

### 四世同堂：大型群戏 Sketch

**核心标签**：多角色调度、经典IP改编、荒谬递进、群体化学反应、现代梗嫁接

**招牌技法**：

1. **经典IP改编——"旧瓶装新酒"**：
   - 把观众熟悉的经典故事（西游记、水浒传、黑帮电影）作为底板
   - 在熟悉的框架中填入全新的、荒谬的内容
   - 优势：观众自带背景知识，不需要铺垫世界观，可以直接进入笑点
   
   **真实案例——《八十一难》**：
   ```
   经典IP：《西游记》取经路上八十一难
   新解读：如果只有八十难，差一难不能成佛，师徒四人得自己"凑"第八十一难
   
   师徒的方案：
   - 悟空："我去打一架回来算一难？"
   - 八戒："让我吃一顿行不行？吃撑了也算难受"
   - 沙僧："我……我有什么用？"（沙僧存在感危机）
   - 师父最终决定：自我牺牲——"如果还差一难，那就让这一难落在我身上"
   ```

2. **沙僧存在感危机——"小角色大戏"**：
   - 在群戏中，故意让某个角色"没有存在感"本身变成笑点
   - 这个角色每次试图参与都被忽视/打断，形成一条独立的笑点线
   
   **真实案例——《八十一难》中的沙僧**：
   ```
   沙僧的台词线：
   "大师兄，我也想出一个主意——"（被打断）
   "师父我——"（被无视）
   "我觉得我——"（被安排去挑行李）
   最后的爆发："我在这个队伍里到底有什么用！"
   → 观众共鸣：每个团队里都有一个"沙僧"
   ```

3. **九世轮回/平行宇宙——结构性荒诞**：
   - 用"轮回"或"平行"结构把同一批角色放进不同的情境中
   - 每个"版本"都有相同的人物但不同的关系
   
   **真实案例——《八十一难》的九世轮回**：
   ```
   师徒四人在九世轮回中：
   第一世：师父是师父
   第二世：师父变成了徒弟
   第三世：师父变成了妖怪
   ……
   每一世都在"凑那最后一难"
   最终——师父自愿成为第八十一难，牺牲自己让三个徒弟成佛
   → 从荒诞开始，到催泪结束
   ```

4. **多线叙事+群聊梗——现代社交映射**：
   - 把多个团伙/派系的互动映射为现代人的社交行为
   - 特别擅长用"群聊""多群""信息差"等现代社交梗嫁接到古代/黑帮情境中
   
   **真实案例——《X计划》**：
   ```
   四个不同的团伙都计划抢同一家银行：
   - 他们各自有自己的"群聊"商量计划
   - 某人同时在多个群里"卧底"
   - "黑吃黑"的过程变成了"信息战"
   - 最后银行推出了"美团团购套餐"，把劫匪都变成了消费者
   
   → 用"多群""信息差""外卖平台"等现代梗解构传统黑帮片
   ```

5. **群体化学反应——"人多但不乱"**：
   - 四世同堂通常4-6人同台，每个人都有鲜明角色
   - 核心技术：用**主副线交替**保持节奏
   - 主线推剧情，副线（某个角色的独立笑点线）在主线间隙填充笑点
   
   **真实案例——《心动的信号》的角色分工**：
   ```
   西西里里家族三兄弟：
   - 老大：表面冷酷，实际啰嗦
   - 老二：暴躁但讲义气
   - 老三（建国）：不务正业但最有人情味
   
   每个兄弟都有独立的笑点线，但三条线在"坏消息救爸"的主线上汇合
   ```

**四世同堂的 Sketch 创作公式**：
```
1. 选一个经典IP/类型片作为底板（观众自带背景知识）
2. 在经典框架中加入一个荒谬的"核心矛盾"
3. 设计4-6个角色，每人一条笑点线
4. 用主线推剧情，副线（角色独立笑点）填间隙
5. 嫁接现代梗（社交媒体/外卖/群聊）到古装/经典场景中
6. 升级路线要清晰：荒谬度逐层递增直到"天花板"
7. 结尾可温情可荒诞，看作品气质决定
```

**适用场景**：需要多人物、大场面、经典IP改编、群体节奏调度的幽默内容。

### 刘同某某某：温情+实验型 Sketch

**核心标签**：温情底色、多线叙事、音乐融合、元喜剧、群像刻画、催泪结尾

**招牌技法**：

1. **温情底色——"搞笑只是手段，感动才是目的"**：
   - 在所有 Sketch 团队中，刘同某某某的情感浓度最高
   - 不只是"最后来一下催泪"，而是全程温情的底色始终在
   - 笑点是浮在温情之上的浪花
   
   **真实案例——《再见老张》**：
   ```
   设定：婚礼彩排。新娘让天使帮她实现一个愿望——见已故的父亲最后一面。
   
   全程在笑（婚礼上的各种乌龙、亲戚的搞笑互动），
   但观众始终知道"爸爸已经不在了"这个情感暗线。
   
   最终：父亲以模糊的方式"出现"，
   女儿给他敬茶、改口叫"爸"、一起走红毯。
   
   "我来不了你的婚礼了，但你要好好的"
   → 全场泪崩。前面笑得越多，这一刻哭得越狠
   ```

2. **多身份错位——每个角色都不是表面那样**：
   - 刘同某某某擅长制造"身份层层剥开"的惊喜
   - 每揭开一层身份就产生一个新笑点
   
   **真实案例——《遇人不熟》**：
   ```
   海盗船上，主角以为大家都是陌生人。
   结果：
   - 这个海盗是你大学室友
   - 那个海盗是你前女友的现男友
   - 船长是你爸的狱友
   - 厨师是你小学同桌
   
   每一层"原来你们认识？！"都是一次笑点爆发。
   最终：整条船上就你一个"陌生人"——
   "你以为你在融入世界，其实世界早就在你不知道的地方连成了网"
   ```

3. **元喜剧——"演员演演员演角色"**：
   - 打破第四面墙，让喜剧创作过程本身成为内容
   
   **真实案例——《谈恋风云》**：
   ```
   设定：一群人在线上排练喜剧节目。
   但各种技术故障（网络卡顿、麦克风没开、画面倒了）成了笑点。
   排练的"失败"本身比"正式演出"更好笑。
   
   元层面的笑点：
   - 排练vs正式：哪个更真实？
   - 技术故障vs人为搞笑：哪个更好笑？
   - 他们在喜剧大赛报名，报名过程本身就是一出喜剧
   ```

4. **音乐/说唱融合——用音乐表达不能直说的话**：
   - 在需要情感爆发或叙事跳跃时，切入音乐/说唱段落
   - 音乐不是"配乐"，是"剧情推进器"
   
   **真实案例——《谈恋风云》中的说唱**：
   ```
   角色用说唱表达对喜剧的热爱和创作的焦虑。
   从对话切到Rap → 信息密度飙升 → 情绪一次性释放 →
   Rap结束后回到日常对话 → 反差产生笑点
   ```
   
   **真实案例——《复活军团》中的摇滚**：
   ```
   寝室里几个人因为一封"遗书"（其实是乌龙）开始互相关心，
   最后他们组了一支摇滚乐队。
   摇滚乐段落是全场最燃的瞬间——
   从"以为室友要离开"的恐惧到"我们要一起做点什么"的热血
   ```

5. **"乌龙→真情→和解"三拍结构**：
   - 所有故事都因为一个乌龙/误会/荒唐事件开始
   - 在解决乌龙的过程中，人物之间的真实情感被逼出来
   - 最终的"和解"不只是解决误会，更是人物关系的升华
   
   **真实案例——《复活军团》**：
   ```
   乌龙：室友在床上发现一封看似遗书的东西
   真情：大家开始回忆和这个室友的点滴，互相说出从未说过的心里话
   和解：发现"遗书"其实是歌词草稿→但情感已经真实地释放了→
        组乐队的决定就此诞生
   ```

6. **偶像文化/粉丝行为的讽刺**：
   
   **真实案例——《饭局往事》**：
   ```
   三个"三小虎"（虚构偶像团体）粉丝在东南亚偶遇，
   结果发现自己陷入了一场黑帮分遗产的闹剧。
   
   讽刺层：
   - 粉丝为偶像做的疯狂事情和黑帮的疯狂行为放在一起，
     突然发现两者的逻辑惊人地相似
   - "追星"和"入帮"的界限变得模糊
   → 在搞笑中完成了对偶像文化的温和反思
   ```

**刘同某某某的 Sketch 创作公式**：
```
1. 从一个日常场景开始（寝室/婚礼/饭局/排练），不用宏大设定
2. 设置一个"乌龙事件"或"误会"作为引爆点
3. 在解决乌龙的过程中，自然展开人物关系和情感
4. 穿插音乐/说唱段落作为情感催化
5. 身份层层揭开，每揭一层是一个笑点
6. 结尾回到温情：人与人之间真正重要的东西是什么？
7. 催泪不要硬来，让观众自己被打到
```

**适用场景**：需要温情打底、有情感深度、多线叙事、音乐融合的幽默内容。尤其适合"笑完之后眼眶湿了"的作品。

### 闫佩伦：黑马型 Sketch 演员

**核心标签**：独特喜感、表演自然、节奏感好

**招牌技法**：
1. **天然喜感**：身体语言和面部表情自带喜剧效果

3. **节奏把控**：知道什么时候该快什么时候该慢

**适用场景**：需要自然、不刻意的幽默效果

## 五、Sketch 写作模板

### 模板一：标准 Sketch 结构

```
[前提建立]
场景：[具体场所]
人物：[人物A]、[人物B]
Game：[核心荒谬前提——用一句话概括]

[第一拍 —— 建立规则]
正常的开场 → 荒谬元素初次出现 → 角色反应

[第二拍 —— 升级]
同一个 Game 再次出现，但程度更深 → 反应更大

[第三拍 —— 再次升级]
Game 升级到新高度 → 牵扯更多人/更多后果

[高潮 —— 顶点]
荒谬达到极致 → 最大笑点

[结尾 —— 三种选择]
选择A：反转收尾（最后一个意外）
选择B：暖心收尾（落到情感上，笑中带泪）
选择C：荒诞收尾（在最高点戛然而止）
```

### 模板二：多角色群戏（酷酷的天放/四世同堂风格）

```
[角色设计]
角色A：[人设 + 核心笑点线]
角色B：[人设 + 核心笑点线]
角色C：[人设 + 核心笑点线]
角色D：[人设 + 核心笑点线]（可选"存在感危机"线）

[核心矛盾]
他们共同面临的问题：[一句话]

[节奏设计]
A出击 → B接住 → C升级 → D（被忽视）→ A回来 →
循环2-3轮，每轮荒谬度递增

[高潮]
所有角色的笑点线在一个场景中同时爆发

[收尾]
温情/讽刺/荒诞三选一
```

### 模板三：温情乌龙（刘同某某某风格）

```
[日常场景 + 乌龙事件]
在 [普通场景] 中，发生了 [一个误会/乌龙]

[乌龙升级]
误会越来越深 → 人物反应越来越大 → 笑点递增

[情感浮现]
在解决乌龙的过程中，[角色A] 说出了 [藏在心底的真话]

[音乐催化]（可选）
切入 [音乐/说唱/歌曲] 段落，一次性释放情感

[和解]
乌龙被解开，但情感已经真实释放了。
关系比误会前更近了一步
```

## 六、Sketch 创作的核心原则

1. **一个 Sketch 只有一个 Game** —— 不要塞太多概念
2. **先找 Game，再找角色** —— 前提决定一切
3. **Show, don't tell** —— 演出来，不要说出来
4. **升级是生命线** —— 如果 Sketch 中途不好笑了，通常是因为没有升级
5. **结尾要干脆** —— 在最高笑点/最强情感处结束，不要拖
6. **角色要有"需求"** —— 每个角色都想要什么东西，需求的碰撞产生戏剧
7. **真实的情感 + 荒谬的情境** —— 情感越真实，荒谬越好笑
8. **群戏要有"主咖"** —— 人再多也要有一个焦点角色，否则观众不知道看谁
