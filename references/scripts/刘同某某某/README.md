## 喜剧技巧特征（基于254,000字素材分析 ✅）

- **温情底色**：在所有Sketch团队中情感浓度最高。不只是"最后来一下催泪"，而是全程温情的底色始终在。笑点是浮在温情之上的浪花。
- **"乌龙→真情→和解"三拍结构**：所有故事因乌龙/误会开始→在解决乌龙过程中真情被逼出来→最终关系升华。《复活军团》的遗书乌龙是典型案例。
- **多身份错位**：每个角色都不是表面那样，每揭开一层身份就产生一个新笑点。《遇人不熟》中海盗船上"陌生人"逐一揭露互相认识。
- **元喜剧**：打破第四面墙，让喜剧创作过程本身成为内容。《谈恋风云》排练的"失败"比正式演出更好笑。
- **音乐/说唱融合**：在需要情感爆发或叙事跳跃时切入音乐段落。音乐是"剧情推进器"，不是配乐。《复活军团》的摇滚乐队段落是全场最燃的瞬间。
- **催泪不硬来**：《再见老张》的父女告别是所有作品中最催泪的——前面笑得越多，这一刻哭得越狠。但催泪不靠煽情台词，靠"场景的真实感"。
