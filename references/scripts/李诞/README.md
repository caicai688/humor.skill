## 喜剧技巧特征（基于254,000字素材分析 ✅）

- **善意贬损法（吐槽大会核心技术）**：找到嘉宾身上的公众认知标签，先承认再用意外角度消解或重新定义。攻击的是标签/现象，不是人本身。
- **消解式幽默**：用一句话消解严肃/崇高话题的意义。"人间不值得"式的轻松虚无。
- **自我矮化+反弹**：主动把自己放低，低到一定程度后反弹出犀利洞察。
- **群体吐槽转个体共鸣**：吐槽名人→引发对普遍现象的共鸣。如吐槽张韶涵消失→打工人工位不保的不安全感。
- **节奏控制（主持人技术）**：在嘉宾段子之间用短平快的"过渡梗"维持热度，冷场时立刻用自嘲或转移话题化解。
- **人设管理**："我不太行但大家都爱我"的人设让观众放松警惕。
