## 喜剧技巧特征（基于254,000字素材分析 ✅）

- **"笑着笑着就哭了"结构**：前70-80%纯喜剧笑点密集，最后20-30%突然转入情感。关键：情感转折必须是"有铺垫的突然"——前面埋的线索在这一刻串起来。
- **音乐作为情感催化剂**：音乐不只是配乐，是剧情推动力和情感爆发点。《杀手不太冷》中歌声暴露内心，《穿越》中吉他段落是最安静也最感动的瞬间。
- **行业讽刺（新维度）**：从纯情感故事→情感+行业洞察。《孙悟空选角》讽刺"资方决定选角"的行业现象。
- **默契互动化学反应**：蒋龙偏"正"（直球、深情、认真），张弛偏"谐"（插科打诨、消解、制造意外），两人配合通过眼神、节奏、语气的微调产生额外喜剧效果。
- **小人物叙事**：主角永远是普通人——追梦的年轻人、不得志的打工族、被误解的小演员。
