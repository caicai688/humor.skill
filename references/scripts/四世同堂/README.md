## 喜剧技巧特征（基于254,000字素材分析 ✅）

- **经典IP改编（"旧瓶装新酒"）**：把观众熟悉的经典故事（西游记、水浒传、黑帮电影）作为底板，填入全新荒谬内容。优势：观众自带背景知识，不需要铺垫世界观。
- **沙僧存在感危机（"小角色大戏"）**：故意让某个角色"没有存在感"本身变成笑点，形成独立笑点线。
- **九世轮回/平行宇宙——结构性荒诞**：用"轮回"结构把同一批角色放进不同情境中，每个"版本"都有相同人物但不同关系。
- **多线叙事+群聊梗——现代社交映射**：用"群聊""多群""信息差"等现代社交梗嫁接到古代/黑帮情境中。《X计划》用多群黑吃黑映射现代信息战。
- **群体化学反应（"人多但不乱"）**：4-6人同台，用主副线交替保持节奏——主线推剧情，副线在间隙填充笑点。
- **荒谬递进**：升级路线清晰，荒谬度逐层递增直到"天花板"。
