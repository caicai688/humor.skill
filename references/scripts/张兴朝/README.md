## 喜剧技巧特征（基于254,000字素材分析 ✅）

- **无厘头至上**：不需要合理的逻辑，荒诞本身就是目的。和其他Sketch团队最大的区别：其他人是"用荒诞讲道理"，张兴朝是"荒诞本身就是道理"。
- **魔性重复+洗脑旋律**：用一段朗朗上口的旋律或台词反复出现，每次出现都有微妙变化（节奏/音调/搭配的动作不同），在观众脑中种下"魔性循环"。
- **技能展示型喜剧**：多才多艺（唱歌、舞蹈、模仿、杂耍），把才艺本身变成笑点。才艺越厉害和荒诞情境的反差越大，越好笑。
- **现场互动+第四面墙突破**：经常直接和观众互动，把观众从"看"变成"参与"。
- **迷惑行为递进**：从"有点奇怪"→"很奇怪"→"完全无法理解"→"观众已经放弃理解开始纯笑"。
- **拒绝意义**：不做情感升华、不讲人生道理，在最荒诞的地方戛然而止。
