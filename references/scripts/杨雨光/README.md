## 喜剧技巧特征（基于254,000字素材分析 ✅）

- **干拔（Hard Pull）**：在没有足够铺垫的情况下，通过表演的爆发力强行把情绪拉到满格。越认真越好笑。
- **多重身份反转**：角色永远不是你以为的那个身份。《开学第一天》中从班长→保安→纪律委员→混混→父亲，层层揭面。
- **历史/奇幻+现代思维碰撞**：把现代语言和价值观放进古代/奇幻场景中，反差天然产生喜剧。
- **一本正经演荒诞**：角色完全不觉得自己在做奇怪的事，观众因为反差而笑。
- **人保戏**：表演能力可以把普通的剧本提升一个档次，眼神表演尤其出色。
- **暖心落地**：过程荒诞搞笑，结尾落到亲情/友情/人性温暖上。
