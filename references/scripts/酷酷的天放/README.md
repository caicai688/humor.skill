## 喜剧技巧特征（基于254,000字素材分析 ✅）

- **强人设驱动**：不靠段子堆砌，每个角色的性格设定本身就产生笑点。《质子的愿望》七个质子七种性格，碰撞自然产生笑点。
- **"弱者胜出"叙事模式**：天放偏爱塑造"看起来最弱但最终赢了"的角色。观众天然代入弱者视角，翻盘时获得双重满足（笑+爽）。
- **现实共鸣嫁接历史/奇幻**：用古装/奇幻外壳包裹当代人的真实困境。《史上第一大劫案》表面是劫案实际是打工人困境集中爆发。
- **群戏调度**：通常4-6个主要角色同台，用"角色轮流出击"方式保持笑点节奏：A→B→C→D→A 循环，无冷场。
- **暖心穿插在笑点之间**：不是最后才催泪，而是在密集笑点中突然插入一句真心话让观众心头一热，下一秒又回到搞笑。
