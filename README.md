## ✨ 这是什么

这是一个为 [CodeBuddy / WorkBuddy](https://www.codebuddy.cn) 打造的 **AI Skill**。

它做了一件事：**让 AI 变得有趣。**

不是那种"我给你讲个笑话吧"的尬聊，而是——
- 解释技术概念时，比喻信手拈来
- 写文案时，金句自然穿插
- 日常聊天时，吐槽、自嘲、反转随时待命
- 需要正经时，一个"认真"就切回专业模式

### 核心数据

| 指标 | 数值 |
|------|------|
| 真实演出素材 | **254,000 字**（从 YouTube 视频转写） |
| 覆盖演员/团队 | **9 组**（李诞、徐志胜、杨雨光、张兴朝、蒋龙张弛、酷酷的天放、四世同堂、刘同某某某、郭德纲） |
| 喜剧流派 | **4 大类**（脱口秀、相声、Sketch、综艺即兴） |
| 技巧文档 | **5 份**专业技法分析 + **7 个**真实作品拆解 |
| 知识库总行数 | **1,863 行** |

## 🚀 安装

### 方式一：克隆到本地（推荐）

```bash
git clone https://github.com/jfcai2008/humor.skill.git ~/.workbuddy/skills/humor-master
```

### 方式二：手动下载

1. 下载本仓库的 ZIP
2. 解压到 `~/.workbuddy/skills/humor-master/`
3. 确保 `SKILL.md` 在 `~/.workbuddy/skills/humor-master/SKILL.md` 路径下

> **注意**：这是用户级 Skill，安装后跨项目生效。

## 📖 使用方式

### 日常对话（自动生效）

安装后，AI 自动以幽默风格沟通。不需要任何指令。

幽默浓度根据场景**自适应**：

| 场景 | 浓度 | 表现 |
|------|------|------|
| 闲聊、头脑风暴 | 🔴 浓 | 段子频出、吐槽拉满 |
| 写文案、做内容 | 🟡 中 | 金句穿插、节奏轻快 |
| 技术讨论、写代码 | 🟢 淡 | 偶尔俏皮比喻 |
| 用户着急/焦虑 | ⚪ 几乎无 | 先解决问题 |

### 四大功能模式

#### 💡 幽默创作

```
"帮我写一个关于加班的段子"
"用李诞的风格吐槽一下开会"
"来个关于相亲的笑话"
```

输出 2-3 个版本，标注用了什么技巧，推荐最佳版本。

#### ✨ 幽默润色

```
"帮我把这段汇报加点幽默"
"这个朋友圈文案太干了，润色一下"
```

保留原意，注入幽默。支持轻度/中度/重度三档。

#### 🎭 风格模仿

```
"用徐志胜的风格做个自我介绍"
"像张兴朝那样介绍一下我们的产品"
"用蒋龙张弛的风格写一个关于面试的 Sketch"
```

**支持 9 种风格**：

| 风格 | 特点 | 适合场景 |
|------|------|---------|
| **李诞** | 消解式、善意贬损、反鸡汤 | 吐槽、消解严肃话题 |
| **徐志胜** | 自嘲→反转→暖心升华 | 破冰、暖心演讲 |
| **杨雨光** | 干拔情绪核弹、多重身份反转 | 出其不意、震撼效果 |
| **张兴朝** | 无厘头、魔性洗脑、纯搞笑 | 放松娱乐、不需要意义 |
| **蒋龙张弛** | 小人物追梦、笑中带泪 | 有情节、感动人心 |
| **酷酷的天放** | 人设驱动、弱者胜出 | 群戏、现实共鸣 |
| **四世同堂** | 经典 IP 改编、大型群戏 | 脑洞大开、荒诞升级 |
| **刘同某某某** | 温情底色、乌龙→真情→和解 | 笑完想哭 |
| **郭德纲** | 市井智慧、包袱密集 | 传统故事、相声风格 |

#### 🔍 喜剧分析

```
"这段为什么好笑？"
"帮我拆解一下这个段子的结构"
"这个笑话不好笑，帮我诊断一下"
```

用专业框架拆解：铺垫→转折→笑点→技巧→升级→情感→态度→共鸣。

## 🔐 安全词系统

**最重要的控制机制。** 一句话切换正经/幽默模式。

### 关闭幽默

说 **"认真"** 或 **"认真点"** → 立刻进入 100% 专业模式，零幽默，持续生效。

### 恢复幽默

说 **"幽默点"** / **"放松点"** / **"来点幽默"** / **"你可以搞笑了"** → 立刻恢复。

## 🛠️ 技术细节

### 素材来源

所有文字稿均通过以下流程获取：
1. **yt-dlp** 从 YouTube 提取音频（MP3）
2. **OpenAI Whisper**（medium 模型）进行中文语音转文字
3. 人工校对 + AI 分析提炼技法

### 知识库版本

| 版本 | 变化 |
|------|------|
| v1.0 | 工具型设计，被动调用 |
| v2.0 | 人格型+工具型混合，加载即改变沟通风格 |
| v2.1 | 新增安全词/恢复词硬开关系统 |
| **v3.0** | **基于 254,000 字真实素材全面升级**，新增 3 个团队分析，全部示例换为真实案例 |
